# Branding

One command renames the product and recolours it:

```sh
pnpm brand --name "Acme" --color "#2563eb"
pnpm brand --name "Acme" --color "#2563eb" --logo ./my-mark.svg
```

| What | Where it is written |
|---|---|
| Product name | `APP_NAME` in both `wrangler.jsonc` files and local `.dev.vars`; `<title>` of both `index.html` (`Acme` and `Acme Admin`); web manifests. Used in emails, sign-in screens and passkey prompts |
| Accent colour | `packages/ui/src/brand.css` between `/* brand:start */` and `/* brand:end */`: `--accent` and `--accent-contrast` for light, and a lightened pair for dark. Text-on-accent is chosen for WCAG AA contrast |
| Icons | `favicon.svg` (adapts to dark mode), `apple-touch-icon.png` (180), `icon-192.png`, `icon-512.png`, `site.webmanifest` in both `apps/*/public/` |
| Logo files | `brand/logo-mark.svg`, `brand/logo-wordmark.svg`, `brand/logo-wordmark-dark.svg` |

Without `--logo`, the default mark is redrawn in your colour and PNGs are generated by a
built-in rasteriser (no tools needed). With `--logo`, your SVG becomes the favicon and
the PNGs are produced with `rsvg-convert`, ImageMagick, Inkscape or macOS Quick Look,
whichever exists; if none does, the script tells you which PNG sizes to export yourself.
The wordmark files are not regenerated from a custom logo.

Restart `pnpm dev` after rebranding and commit the changed files.

## Beyond colour

- All design tokens (surfaces, text, borders, radius, shadows; light and dark) are CSS
  variables in `packages/ui/src/styles.css`. See [ui.md](ui.md).
- Email wording is in `packages/core/src/auth/routes.ts` and `tenant-app.ts` (protected
  files: changing them needs `pnpm guard:approve`).
- Internal names (`rose-app`, `rose-admin`, the `rose_` API key prefix, `X-Rose-*`
  headers, cookie names) are identifiers, not branding. Leave them unless you have a
  reason; they are referenced by tests and the guard.

See [`brand/README.md`](../brand/README.md) for the default palette and logo usage.
